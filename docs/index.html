Running 5+ projects, each with its own agent in a separate tab, gets messy fast — wrong-tab prompts, no overview, lost sessions.

CmdrZone gives you one place to see and drive them all. A stable color and live status per project mean a glance tells you what's working, what's waiting on you, and what's done.

Every terminal runs a real PTY with your full login-shell PATH — so claude, node and pnpm just work, every time.

Everything in one window

A command center, not a tab graveyard

Agents, their diffs, git, a board and an editor — per project, with the agent context built in.

01 / AGENTS

Embedded agent terminals

Every installed agent — Claude Code, Codex, Aider, Gemini, opencode — gets its own launch button in every project, detected automatically. Real PTYs with your full login-shell PATH, side by side, and a ▾ menu to start in a worktree or resume the last conversation.

02 / CHANGES

See what the agent did new

A Changes tab with +/− counts and a side-by-side Monaco diff — scoped to uncommitted, since the agent started or after turn N. Every turn is checkpointed into hidden git refs (untracked files included, your branch untouched), so you can revert to any checkpoint.

03 / SHIP

Commit → push → PR in one click new

Tick the files, press ✨ Draft with Claude for a commit message and PR text that match your repo's style, then Commit, Commit & push, or Commit, push & PR via the GitHub CLI. PR state shows as a badge on the branch.

04 / PARALLEL

Parallel agents in git worktrees

Start an agent in an isolated checkout on its own cz/<name> branch and run several on the same repo without collisions. Worktrees show up in the project tree with their own status; Merge & remove or discard when done.

05 / BOARD

Board → launch from a card

A per-project Kanban with due dates, a ★ priority star and image attachments (paste with ⌘V). Hit ▶ on a card to open a Claude session seeded with its text and images — the card slides to In Progress.

06 / TMUX

Durable sessions

With tmux installed, each terminal attaches to a detached session. Quit the app — your agents keep running — and they reattach on next launch. Closing a tab is the only thing that ends a session.

07 / HOME

A living dashboard

An ambient organism with one glowing nucleus per running agent, a line that says what they're doing, and Up next across every board.

08 / STATUS

Exact agent status

Working / waiting / done straight from Claude Code's own hooks, the tool being run, and a notification carrying the actual question.

09 / MODES

Permission modes

Supervised, Auto-accept edits, Plan or Full access — per project, mapped onto each agent's own CLI flags.

10 / THEMES

Themes, yours too new

Six built-in, light ones included, plus any VS Code theme or one you color yourself. See them ↓

11 / EDITOR

Editor & design

Monaco (VS Code's editor) with multi-file tabs and IntelliSense, and a Design tab that embeds your Figma file next to the agents.

12 / MCP

Agent CLI & MCP

A cmdrzone CLI and an MCP server let agents file and move board cards themselves — no GUI needed.

13 / PROJECTS

Live project tree

Every project and monorepo sub-project under a root folder you pick, with pins, a stable color, git dirty count and live agent status. ⌘N turns an idea into a ready repo with AGENTS.md seeded and an agent on it.

14 / KEYBOARD-FIRST

Split panes & ⌘K everything

Split any tab into row/column panes, each its own live PTY. A ⌘K fuzzy switcher, ⌃Tab through active projects, and jumps to whichever agent is waiting on you.

make it yours

Six themes — or bring your own

Pick a theme in Settings and the whole app reskins — chrome, terminals and the Monaco editor. Dark, grayscale, light, retro — or import any VS Code theme and fine-tune all 27 colors with a live preview. Below: CmdrZone wearing Total Commander, down to the silver bevels and F-key bar.

Install

Download CmdrZone

v0.11.0 for Apple Silicon Macs. Open the DMG and drag CmdrZone to Applications — then two quick steps.

Download .dmg → All releases & notes
zsh — after installing
❯xattr -dr com.apple.quarantine /Applications/CmdrZone.app  # once, before first launch
❯brew install tmux  # durable sessions: agents survive quitting the app

Without the first step macOS says the app is “damaged” or “can't be opened”. Without tmux everything works, but sessions end when CmdrZone closes. Have claude (or another agent CLI) on your PATH and CmdrZone finds it by itself — no setup. The app tells you when a new version is out.

For contributors · Intel Macs

Build from source

macOS · Node ≥ 20 · pnpm ≥ 10 · Xcode Command Line Tools. Clone, install, rebuild native modules, run.

zsh — setup
❯git clone https://github.com/Innoveramera/cmdrzone.git
❯cd cmdrzone && pnpm install
❯pnpm rebuild:native  # rebuild node-pty + better-sqlite3
❯pnpm dev  # launch with hot reload

Full install, packaging & daily-use instructions → the docs.
